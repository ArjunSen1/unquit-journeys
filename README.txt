UNQUIT JOURNEYS. Static app. No server, no database, no tracking.

Upload the whole folder to any web host, or open index.html locally.

index.html          Landing page and the locked order (87 journeys, built ones linked)
ledger.html         Your evidence. One locked sentence per journey, kept on the player's device only
journeys/           One self-contained page per journey (no external files needed)
stickers/           Sticker art per journey: full sticker (svg, png) and the bare object (svg)
scripts/            The script document for each journey, with facts and flags, for editing and review

Adding a journey: write its script as a data file in the same shape as the others, build its page,
draw its object, add its sticker, then turn its row in the order on index.html from grey to black.
Nothing else changes. One story at a time.

Design: black, white, Unquit red (#8E1B1B), Calibri, no icons. The player's words appear in red.
